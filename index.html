Справочник команд Cisco IOS CLI & Диагностики

Используйте эти команды во встроенном терминале маршрутизаторов, коммутаторов и рабочих станций.

Режимы работы IOS
enable

Переход из пользовательского режима (Router>) в привилегированный (Router#).

configure terminal (conf t)

Вход в режим глобальной конфигурации устройства (Router(config)#).

exit / end

Выход на один уровень выше или возврат в привилегированный режим.

Настройка интерфейсов
interface gig0/0 (int g0/0)

Выбор сетевого интерфейса GigabitEthernet0/0 для настройки.

ip address 192.168.1.1 255.255.255.0

Назначение IPv4-адреса и маски подсети на выбранный порт.

no shutdown (no shut)

Включение порта (перевод из состояния administratively down в UP).

Проверка и мониторинг
show ip interface brief (sh ip int br)

Краткая таблица всех интерфейсов, их IP-адресов и статусов (up/down).

show ip route

Просмотр таблицы маршрутизации (Connected сети и шлюзы).

show running-config

Отображение текущей активной конфигурации устройства.

Диагностика сети (ПК и Роутер)
ping 192.168.1.2

Отправка ICMP Echo-запросов с визуальной анимацией прохождения пакета по кабелям.

ipconfig (на ПК / Сервере)

Просмотр IP-адреса, маски подсети и основного шлюза рабочей станции.

arp -a

Просмотр ARP-таблицы соответствия IP-адресов и MAC-адресов.
